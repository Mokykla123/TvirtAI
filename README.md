# Tvirt(AI)

Programa sukurta su [MIT RAISE Playground](https://playground.raise.mit.edu/main/).

## Kaip atsidaryti ir išbandyti programą?
1. Viršuje esančiame failų sąraše spauskite ant **`TvirtAI.sb3`**.
2. Atsidariusiame lange dešinėje pusėje spauskite **Download raw file** (atsisiuntimo rodyklės ikoną), kad išsaugotumėte failą savo kompiuteryje.
3. Atsidarykite [https://playground.raise.mit.edu/main/](https://playground.raise.mit.edu/main/).
4. Viršutiniame meniu spauskite **File** → **Load from your computer**.
5. Pasirinkite atsisiųstą **`TvirtAI.sb3`** failą ir spauskite žalią vėliavėlę programai paleisti.
